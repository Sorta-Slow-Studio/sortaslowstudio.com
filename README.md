# Sorta Slow Studio
We are a studio with governance run by sortition, and games made entirely by volunteers (currently)

## About
Sorta Slow Studio is a game studio built around **sortition**. We are inspired by [Sortition USA](https://sortitionusa.org/).
Our governance and constitution can be found [here](https://github.com/Sorta-Slow-Studio/constitution).

We make games for our community that are built with the principle of shared responsibility and service. Our goal is to develop games that make are inclusive, welcoming, and fun. (mission to be determined)
